# Карта проекта «Далеко собрались?»

Собранный сайт — один файл `index.html`. Он склеивается из исходников в папке `v10/` скриптом `b10.sh`: стили, разметка, `scenery.js`, `app.js`, фотографии подставляются как data-URI.

## Исходники
| Файл | Что внутри |
| --- | --- |
| `v10/body.html` | Разметка всех сцен, заготовки рисунков (бык, лошадь, бегун, повозка, гравюра колеса `#wheelArt`), колесо-проводник `#guide`, титры, подвал |
| `v10/style.css` | Шрифты (Alegreya SC + Alegreya), плёнка, сцены, коллажи `.collage`, вырезки `.cut`, наклейки-предметы `.stk`, фотоэкраны `.pscreen`, мобильная версия |
| `v10/app.js` | Звук (синтез в браузере), фигуры для морфинга `FIG`, движок сцен (`data-k`), разрывы интертитров, логика каждой сцены, ключевые кадры колеса-проводника `KF`, перемотки |
| `v10/scenery.js` | Рисованные пейзажи: `hero`, `later`, `parade`, `day`, `nag` |
| `photos/` | Фотографии из Викисклада (`meta.json` — авторы и лицензии), вырезки `C_*`, `T_*`, наклейки-предметы `S_*`, крупные фото `H1–H4` |
| `art/wheel.py` | Генератор гравюры деревянного колеса |
| `cut/gc.py` | Вырезание предметов из фото (OpenCV grabCut) с бумажным контуром |

## Порядок сцен (id секций)
1. `open` — «Далеко собрались?» → «Ловите!» → «Не успели.» → склейка → дата «Сегодня…» прокручивается в «около 4000 г. до н. э.» → перемотка
2. `open2` — «Как теперь его догнать?», два варианта
3. `later` — интертитр + лента изобретений (флейта-наклейка, Ласко)
4. `ps1` — фотоэкран «Пять тысяч лет в болоте»
5. `swamp` — разрез болота, «И вдруг — тук», колесо-наклейка
6. `find` — таблица находки на бумаге
7. `ps2` — фотоэкран «Колесо есть. Ехать не на чем.»
8. `eq` — интертитр + «Одного колеса мало», уравнение в картинках, кувшин из Броночице
9. `lab` — «Соберите свою повозку» (земля с травой)
10. `nag` — Нагасена и Милинда разбирают колесницу
11. `ps3` — фотоэкран «А потом поехали»
12. `parade` — телега, колесница, дрезина, автобус + наклейки
13. `day` — интертитр + день вокруг колеса
14. `ps4` — фотоэкран «Колесо давно с нами»
15. `rounds` — таблетка, руль, колесо обозрения… → «Это как всё вокруг» → сансара → перемотка в начало и титры

## Где что менять
- Текст сцены — в `v10/body.html`, найти по id секции.
- Когда что появляется — атрибут `data-k="начало,конец[,исчезает_с,исчезает_по]"` в долях прокрутки секции.
- Где колесо-проводник и во что превращается — массив `KF` в `v10/app.js`.
- Звуки — объект `SND.fx` в `v10/app.js`.
- Пересобрать: `sh b10.sh` → `v10.html` (для публикации) и `v10s.html` (= `index.html`).

## Что стоит поправить по лекциям
- Соседская дверь (1.1, 1.3, 1.8): ссылка к первоисточнику — отчёт о колесе из Любляны, статья о кувшине из Броночице. Подписать по смыслу, не «подробнее».
- Тезис одной фразой и строка «это не проект об истории транспорта вообще» (1.2) — проверить, держатся ли на нём сансара, Нагасена и «день вокруг колеса».
- Карточка зон с плотностью 1–5 (1.3): лента изобретений → формула с кувшином → лаборатория идут тремя тяжёлыми зонами подряд; между ними нужна передышка.
- Одно главное свойство браузера и одно поддерживающее (1.1); мерцание, звук и прочее проверить по Такеру.
- Перед показом (1.8): чистое окно, телефон, клавиатура, медленная сеть, запись прохождения, карточка версии 1.0.

## Граф Graphify
Полный граф проекта: `graphify-out/` в корне longrid — 435 узлов, 964 связи, 14 групп; все восемь лекций внесены полными текстами. Graphify стоит на Mac (uv, версия 0.9.92).
- `graphify-out/graph.html` — интерактивная карта в браузере; `GRAPH_REPORT.md` — главные узлы и группы; `graph.json` — сам граф (`graphify query "вопрос"`).
- Карта в Obsidian: папка `docs/Карта Graphify` — заметка на каждый узел, холст `graph.canvas`, вход — [[00 Карта проекта]].

Как собран: код (`src/app.js`, `src/scenery.js`, `art/wheel.py`, `cut/gc.py`, `b10.sh`) разобран точно на Mac; разметка, стили, MAP.md, context.md и лекции 1.1, 1.2, 1.3, 1.8 — смысловым извлечением; связи кода со сценами добавлены вручную (INFERRED).

Обновление: после каждого коммита git-хук `.git/hooks/post-commit` в фоне пересобирает граф и карту в Obsidian (лог: `~/.cache/longrid-graphify.log`). Вручную, в папке longrid:
```
graphify extract . --code-only && graphify cluster-only . && graphify export obsidian --dir "docs/Карта Graphify"
```
Смысловой слой при этом сохраняется. Что не читается: `.graphifyignore`. Старый черновой граф — `docs/graphify-out/`.

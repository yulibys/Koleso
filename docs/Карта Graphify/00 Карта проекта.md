# Карта проекта (Graphify)

Граф лонгрида «Далеко собрались?»: 435 узлов, 964 связей, 14 групп. В графе код сайта, разметка и стили, журнал решений, карта MAP и все восемь лекций Олега Пащенко (1.1–1.8) полными текстами. Каждая заметка в этой папке — узел графа, вики-ссылки — его связи. Граф целиком удобнее смотреть в виде графа Obsidian (Cmd+G) с фильтром `path:"docs/Карта Graphify"`.
